
# 📚 Proyecto LMS (Learning Management System)

Este proyecto consiste en el desarrollo de un **sistema de gestión del aprendizaje (LMS)** moderno, adaptable y modular, inspirado en el dashboard de referencia [demo LMS](https://astounding-clafoutis-196412.netlify.app/).  

El objetivo principal es brindar a **administradores, docentes y estudiantes** una herramienta que facilite la creación, gestión y seguimiento de cursos, lecciones y evaluaciones, con una interfaz intuitiva y personalizable.
